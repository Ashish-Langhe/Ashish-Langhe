## 🧭 About Me

> *"I don't just ship features — I architect mobile experiences that scale to millions of users."*

I'm a **Senior iOS Engineer** with **9+ years** of building and scaling mission-critical mobile applications at **Disney**, **HSBC**, **Wizink Bank**, **Ferrovial**, and **ICICI Lombard** — via **Globant** and **Wipro**. I've led teams of up to 40, driven UPI payment integrations for one of India's largest banks, and ranked **#1 in HSBC-Wipro's Secure Code Warrior Tournament** across 200+ engineers.

I specialise in clean architecture, performance engineering, security-first development, and increasingly — **AI-assisted workflows** using GitHub Copilot, Claude, Amazon Q, and Gemini.
